GPT Header Reference Table

GPT disks normally use a protective MBR at LBA 0 and the primary GPT header at LBA 1.

Typical GPT Disk Layout

LBAPurpose
0Protective MBR, normally with partition type 0xEE.
1Primary GPT Header.
2 and followingPartition Entry Array.
End of diskBackup Partition Entry Array and backup GPT Header.

GPT Header Fields

OffsetSizeFieldNotes
0x008SignatureASCII EFI PART.
0x084RevisionLittle-endian GPT revision.
0x0C4Header sizeUsually 92 bytes.
0x104Header CRC32Checksum of GPT header.
0x188Current LBAUsually 1 for the primary header.
0x208Backup LBALocation of backup GPT header.
0x288First usable LBABeginning of usable partition space.
0x308Last usable LBAEnd of usable partition space.
0x3816Disk GUIDUnique identifier for the disk.
0x488Partition Entry Array LBAStarting LBA of partition-entry table.
0x504Number of partition entriesCommonly 128.
0x544Partition entry sizeCommonly 128 bytes.
0x584Partition array CRC32Checksum of partition entries.

Useful Calculations

byte offset of LBA N = N × sector size

For 512-byte sectors, GPT header at LBA 1 begins at byte offset 512.

Signature check: if bytes at LBA 1 begin with ASCII EFI PART, you are looking at a GPT header.
