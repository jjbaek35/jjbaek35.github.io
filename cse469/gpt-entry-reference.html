GPT Partition Entry Reference Table

A standard GPT partition entry is commonly 128 bytes. Confirm the actual entry size from the GPT header before assuming 128.

GPT Partition Entry Fields

Relative offsetSizeFieldNotes
0x0016Partition Type GUIDIdentifies partition type.
0x1016Unique Partition GUIDUnique identifier for this partition.
0x208First LBA64-bit little-endian starting sector.
0x288Last LBA64-bit little-endian ending sector, inclusive.
0x308Attributes64-bit attribute flags.
0x38–0x7F72Partition name36 UTF-16LE characters.

Partition Size

number of sectors = Last LBA - First LBA + 1

partition size in bytes = number of sectors × sector size

Partition Name

The 72-byte name field is encoded as UTF-16LE. A forensic workflow may extract those 72 bytes and decode them with iconv or Python.

Example: each ASCII-range UTF-16LE character often appears as the character byte followed by 00.

Helpful inspection tools

xxd, hexdump, od, dd, strings, iconv, python3
