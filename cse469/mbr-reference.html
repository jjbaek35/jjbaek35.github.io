MBR Reference Table

This page is a quick reference for raw-sector analysis in the disk-forensics lab.

MBR Sector Layout (512 bytes)

OffsetSizeFieldNotes
0x000–0x1BD446 bytesBoot code / data areaMay contain boot code or other data.
0x1BE–0x1CD16 bytesPartition entry 1First MBR partition entry.
0x1CE–0x1DD16 bytesPartition entry 2Second MBR partition entry.
0x1DE–0x1ED16 bytesPartition entry 3Third MBR partition entry.
0x1EE–0x1FD16 bytesPartition entry 4Fourth MBR partition entry.
0x1FE–0x1FF2 bytesBoot signatureNormally 55 AA.

MBR Partition Entry (16 bytes)

Relative offsetSizeFieldInterpretation
0x001Boot indicator0x80 active, 0x00 inactive.
0x01–0x033Starting CHSLegacy geometry field; often not used for modern offset calculations.
0x041Partition typeExamples: 0x07 NTFS/exFAT, 0x0B/0x0C FAT32, 0xEE protective GPT.
0x05–0x073Ending CHSLegacy geometry field.
0x08–0x0B4Starting LBA32-bit little-endian sector number.
0x0C–0x0F4Sector count32-bit little-endian number of sectors.

Useful Calculations

byte offset = starting LBA × sector size

For a 512-byte-sector image: offset = LBA × 512.

Endian reminder: values such as Starting LBA are stored little-endian. Bytes 00 08 00 00 represent 0x00000800, or decimal 2048.

Helpful inspection tools

xxd, hexdump, od, dd, file, strings, python3
